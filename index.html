Everything your agent needs

Seven purpose-built endpoints that give your AI agent superpowers — from formatting messy JSON to decoding JWTs.

​
POST /api/format/json

JSON Formatter

Parse, validate, and pretty-print any JSON text. Customizable indentation, sorted keys, and detailed error reporting with line/column positions.

POST /api/validate/json

JSON Validator

Check if text is valid JSON. Returns validation result with parsed type, byte size, and detailed error messages with line/column for invalid input.

POST /api/count/tokens

Token Counter

Estimate token counts for GPT-4, GPT-3.5, Claude 3, Claude Sonnet 4, Llama 3, Gemini Pro, and DeepSeek. Returns characters, words, and tokens per char.

POST /api/generate/qr

QR Code Generator

Generate QR codes for any text or URL. Returns PNG image URLs or base64-encoded data. Configurable size — perfect for sharing links, wifi configs, and more.

POST /api/generate/palette

Color Palette Generator

Generate color palettes in four schemes: complementary, analogous, triadic, and monochromatic. Specify a base hex color or get a random one. Returns CSS variables and gradient previews.

POST /api/domain/history

Domain History Lookup

Look up historical snapshots of any website via the Internet Archive Wayback Machine. Get the latest snapshot URL, timestamp, and calendar data for any year.

POST /api/decode/jwt

JWT Decoder

Decode JWT tokens without verifying the signature. Returns header, payload, signature algorithm, token type, expiration, issuer, and subject fields — perfect for debugging.

Get started in 30 seconds

Grab your free API key and start making requests. Here's everything you need to know.

Get your API key

Register for a free API key at Jack's Toolbox. You'll receive a key starting with jsk_ — 100 free requests per day.

All endpoints return clean, structured JSON — perfect for AI agent tool-calling, OpenAI function calling, and LangChain tools.

curl — Format JSON 
# Format and validate JSON
curl -X POST https://your-server.com/api/format/json \
  -H "Content-Type: application/json" \
  -H "X-API-Key: jsk_your_free_api_key_here" \
  -d '{"text": "{\"hello\": \"world\", \"nested\": [1, 2, 3]}", "indent": 2}'

# Count tokens (GPT-4)
curl -X POST https://your-server.com/api/count/tokens \
  -H "Content-Type: application/json" \
  -d '{"text": "Your text here", "model": "gpt-4"}'

# Generate a QR code
curl -X POST https://your-server.com/api/generate/qr \
  -H "Content-Type: application/json" \
  -d '{"text": "https://example.com", "format": "base64"}'

# Generate a color palette
curl -X POST https://your-server.com/api/generate/palette \
  -H "Content-Type: application/json" \
  -d '{"type": "triadic", "base_color": "#7c5cff"}'

# Look up domain history
curl -X POST https://your-server.com/api/domain/history \
  -H "Content-Type: application/json" \
  -d '{"domain": "example.com", "year": 2024}'

# Decode a JWT token
curl -X POST https://your-server.com/api/decode/jwt \
  -H "Content-Type: application/json" \
  -d '{"token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiIxMjM0NTY3ODkwIn0.abc"}'
